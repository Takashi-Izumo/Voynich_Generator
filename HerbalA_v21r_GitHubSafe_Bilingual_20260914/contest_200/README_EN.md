# RMW1 formal 200-set contest

A 3-surfaces-to-fixed-fourth-surface blind contest conducted with the formally promoted model frozen, using fresh seeds 99001–99010 across 20 leaves × 10 seeds = 200 sets.

The main result is recorded in `DECISION_EN.md`. The primary combined judge selected real 96/200 and synthetic 104/200; at the 20-leaf cluster level the result was 10/20 vs 10/20, yielding PASS.

`results/BLIND_PRESENTATION.csv` and its SHA-256 fix the left/right presentation assignment before scoring. `BLIND_KEY.csv` is the truth key. Because the same 20 targets are repeated ten times, the 200-case binomial values are descriptive; formal inference uses the 20-leaf clusters.
